# 前提と仮定

<!-- markdownlint-disable MD013 -->

文書の結論が何を前提にして成り立っているかを洗い出し、その前提が明示されているか、崩れたときに結論がどうなるかが検討されているかを見る。

## 前提が書かれていない

- 見るところ: 効果、費用、期間の見通しが、その計算に使われた条件（利用率、採用率、人員数、単価、期間）の記述なしに書かれている箇所
- 確かめ方: 各見通しの数値を導くのに必要な条件を列挙し、文書内でそれぞれが明示されているかを確認する。明示されていない条件があれば質問にする
- 求める材料: 見通しごとに、計算に使った条件の一覧と各条件の値

## 楽観シナリオしかない

- 見るところ: 効果や収益の見通しが 1 通りしか書かれていない箇所、または最良の場合だけが本文に書かれている箇所
- 確かめ方: 見通しの数値が複数の場合分け（悲観、標準、楽観）で示されているかを確認する。1 通りしかなければ質問にする
- 求める材料: 悲観、標準、楽観の 3 通りの見通しと、それぞれの前提の値

## 感度分析がない

- 見るところ: 利用率、採用率、単価、期間のように、少し変わると結論が大きく動く変数が使われている計算
- 確かめ方: 結論に効いている変数を文書内の計算から特定し、その変数を 2 割悪化させたときに結論（投資回収、損益、期限）がどう変わるかが文書内に書かれているかを確認する。書かれていなければ質問にする。自分で 2 割悪化させて計算し直し、結論が逆転するなら、その計算結果を添える
- 求める材料: 主要な変数ごとに、値を上下させたときの結論の変化を示した表または計算

## 前提が崩れたときの影響が書かれていない

- 見るところ: この前提が成り立てば、の形で書かれた見通し、または前提を明示せずに結論だけ書かれた見通し
- 確かめ方: 各前提について、成り立たなかった場合に結論がどうなるか、どの時点で気づけるかが文書内に書かれているかを確認する。書かれていなければ質問にする
- 求める材料: 前提ごとに、崩れた場合の影響の大きさ、検知の方法と時点、そのときの対応

## 採用率や利用率の根拠がない

- 見るところ: 全員が使う、8 割が移行する、初月から定着する、のような利用側の行動に関する前提
- 確かめ方: その率を裏付ける過去の類似導入の実績、パイロットの結果、ユーザーの意向調査が文書内にあるかを確認する。なければ質問にする
- 求める材料: 過去の類似施策での実際の採用率、またはパイロットの結果と、それが今回に当てはまる理由

## 成長率や規模の前提が根拠なく置かれている

- 見るところ: ユーザー数、取引量、データ量、人員が年率 N % で増える、N 年後に M 倍になる、のような前提
- 確かめ方: その成長率の出所（過去の実績、事業計画、外部予測）が文書内に書かれているかを確認する。書かれていなければ質問にする。過去の実績が文書内にあれば、その実績から計算した成長率と前提の成長率を比較し、乖離があれば矛盾として断定する
- 求める材料: 成長率の出所と、過去 2 期以上の実績との比較

## 外部環境の前提が固定されている

- 見るところ: 為替、ベンダーの価格、法規制、外部 API の仕様、競合の動きが現状のまま続くことを前提にした費用や効果
- 確かめ方: 計画期間中に外部要因が変わる可能性と、その場合の影響が文書内で言及されているかを確認する。言及がなければ質問にする
- 求める材料: 影響する外部要因の列挙と、それぞれが変わった場合の費用や効果への影響

## 前提同士が矛盾している

- 見るところ: 人員は増やさない、と、対応件数を 2 倍にする、のように、別々の節に書かれた前提
- 確かめ方: 文書内の前提をすべて抜き出して並べ、同時に成り立たない組み合わせがないかを確認する。両立しない組み合わせがあれば矛盾として断定する
- 求める材料: 矛盾する前提のどちらを採るかの確定と、それに合わせた見通しの再計算

## 期限の前提に余裕がない

- 見るところ: 導入完了時期、効果が出始める時期、移行完了時期の記述
- 確かめ方: 期限に至る工程と各工程の所要期間が文書内に書かれているかを確認し、書かれていれば所要期間を足し合わせて期限と整合するかを計算する。合わなければ矛盾として断定する。工程が書かれていなければ質問にする
- 求める材料: 工程ごとの開始と終了の時期、依存関係、遅延した場合の期限への影響

## 人員の前提が確保されていない

- 見るところ: 担当者を N 名アサインする、既存メンバーが兼務する、のような人員の前提
- 確かめ方: その人員が現在何を担当していて、どう空けるのか、上長の合意があるのかが文書内に書かれているかを確認する。書かれていなければ質問にする
- 求める材料: 担当者ごとの現在の担当業務、割く工数、空けるために止める業務、所属長の合意の有無

## 現状維持と比較していない

- 見るところ: 提案を実行した場合の効果だけが書かれていて、何もしなかった場合の推移が書かれていない箇所
- 確かめ方: 現状維持の場合の費用、リスク、機会損失が文書内に書かれているかを確認する。書かれていなければ質問にする
- 求める材料: 何もしない場合の同じ期間の費用と影響を、提案と同じ指標で並べた比較

## 代替案の前提と比較していない

- 見るところ: 提案が 1 案だけで、他の選択肢（別ツール、内製、外注、規模縮小）が書かれていない、または検討したと書かれているが比較の中身がない箇所
- 確かめ方: 代替案の名称、費用、効果、採らなかった理由が文書内に書かれているかを確認する。書かれていなければ質問にする
- 求める材料: 検討した代替案ごとの費用、効果、期間と、採らなかった理由

## 効果の発現時期が前提と合っていない

- 見るところ: 導入直後から効果が出る前提で年間効果が計算されている箇所
- 確かめ方: 導入期間、習熟期間、移行期間が文書内に書かれているかを確認し、書かれていればその期間を差し引いて初年度の効果を再計算する。書かれている年間効果と一致しなければ矛盾として断定する。期間が書かれていなければ質問にする
- 求める材料: 効果が出始める時期とその根拠、初年度の効果を期間按分した計算

## 前提の責任者が書かれていない

- 見るところ: 見通しの前提となる条件（人員確保、他部門の協力、予算の追加）で、誰がその条件を成立させるのかが書かれていない箇所
- 確かめ方: 各前提について、成立させる責任者と合意の状況が文書内に書かれているかを確認する。書かれていなければ質問にする
- 求める材料: 前提ごとの責任者、合意の有無、合意した日時と相手
