# マークダウン出力ルール（plain-markdown）

ファイル（`.md` など）への書き出し、または外部ツール（Notion・Slack・GitHub PR 本文など）へのマークダウン書き込みでは、装飾を排した素のマークダウンで書く。このターミナルでのチャット返信には適用しない。

- 太字（`**...**`）を使わない。区切りが要るなら見出し（`##`）で表す。
- コードブロックは実コード（ソース・シェルコマンド・設定ファイル）のみ。ログ・出力・プレーン文を囲わない。単体のパス・識別子・短いコマンドはインライン code で書く。
- 絵文字・水平線（`---`）・blockquote/callout・装飾目的の表を使わない。表は本来の表形式データのみ。

詳細と良い例/悪い例は clean-markdown スキルを参照する。
